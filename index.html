• Can a Single HTML File with CDN JS be a PWA? Yes! RENDRA dynamically injects a Web App Manifest and uses the browser's CacheStorage API (caches.open('rendra-cdn-v1')) to cache three.js and openskp CDN modules locally. When served over HTTPS with a standard Service Worker, those cached CDN modules load 100% offline.

• Optimal SketchUp File Size: 1 MB – 120 MB .skp files parse in 0.5–10 seconds locally in RAM (~300 MB browser tab ceiling).
